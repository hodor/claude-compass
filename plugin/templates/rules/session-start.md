# Compass Session Start

When starting any session in this project, your first actions are to orient:

1. Read `.compass/index.md` - the map of all project documents.
2. Read `.compass/active.md` - current tasks and in-progress work.
3. Read `.compass/vision.md` if it exists - the project goal and spec roadmap.

If a handoff exists from a previous session, find the most recent one in `.compass/handoffs/` and read it. It will tell you where the prior session left off and what needs picking up.

Do this before responding to the user's first message, unless the user explicitly tells you not to.
