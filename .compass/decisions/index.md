# decisions

## Scope

Class here: ADRs - each records a fork that was actually reached and resolved, with the options that were live and both the good and bad consequences.

Domains: [[decisions/distribution/index|distribution]] (installing and updating Compass), [[decisions/learning/index|learning]] (capture and feedback), [[decisions/pipeline/index|pipeline]] (workflow stages and gates), [[decisions/vault-structure/index|vault-structure]] (the vault's own memory). The root holds the founding ruling and ADRs whose placement is unsure, marked with a `taxonomy_hint`.
