When several research agents write into the same domain folder in parallel for one spec, each risks re-finding what a sibling already recorded.
Two independent SPEC-023 researchers read every existing sibling doc before drafting, then wrote their own Scope section to exclude what a sibling already owns, linking to it instead of restating it.
Why: the fan-out itself creates the overlap; checking siblings first is cheaper than a reviewer reconciling duplicate findings afterward.
