A researcher on a broad web axis can spend all 30 turns searching and reading, then stop with nothing written to its output file.
Prevention is in the brief: create the output file within the first few turns, then append each finding as it is confirmed.
A file holding partial findings survives a turn-limit stop; a plan to write at the end does not.
Pair with [[LESSON-long-agents-stall-resume-them]], which covers resuming once a stall has already happened.
