A mechanism buys nothing where the condition it serves is absent. Shape Up's per-wave appetite rations scarce human throughput; the human cut it because AI build speed makes that scarcity noise ([[SPEC-015-rolling-wave-planning]] D-03).
Cache inclusion pays off only when one structure is probed instead of the other, and Compass loads both every turn, so the payoff is structurally absent rather than merely small ([[RESEARCH-cache-theory-for-context-tiers]]).
Name the precondition the source mechanism runs on - the scarce resource, the eviction traffic, the exact-match comparator - and check this project has it before the finding reaches a recommendation.
Mark each imported finding as maps or metaphor and state what a metaphor cannot answer, or a planner will read tag-width math as a summary-length answer.
Carry an import whose precondition is missing or unchecked as a flagged option, never inside the recommendation.
