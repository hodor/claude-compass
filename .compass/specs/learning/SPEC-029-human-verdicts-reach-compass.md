# Human Verdicts on Compass Documents Reach Compass Itself

## Problem

We need to give the human the chance sometimes to say how good or bad a spec is using our new md editor tools.

## Desired Outcome

We should always have a feedback about this spec/thing that goes DIRECTLY TO THE MAIN COMPASS SERVER, we anonymize the data and we store this in a way that IS PRIVATE so that YOU can work on it regardless of where it came from.

The human should always have the possibility to give feedback.

KPI: [guess: every verdict the human gives reaches the main Compass server, none of it can be traced back to the project or person it came from, and it is used to improve Compass.]
