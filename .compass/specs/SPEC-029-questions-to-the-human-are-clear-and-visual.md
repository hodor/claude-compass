# Questions to the Human Are Clear and Visual

## Problem

I want to ensure that when Compass asks questions to the user, it's insanely clear and visual to the user, like it opens a UI to do it. Questions to the human need to be one by one as well.

## Desired Outcome

This is done here, through a Compass control loop, so every question Compass asks the user meets that bar and keeps meeting it as new questions are added.

KPI: [guess: every point where Compass asks the human something goes through the clear, visual way of asking.]
