# Judge rules

- R1: Every instruction, rule or fact removed from a file under `plugin/templates/rules/`, or from a `name`, `description` or `when_to_use` field, appears word for word or in equal meaning in another file under `plugin/` that an agent reads when the work needs it, and the file it left names or links that place.
- R2: No sentence that a gate, a test, a guard or the human's approval relies on was weakened, softened or made optional.
